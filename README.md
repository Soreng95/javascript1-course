# JavaScript 1 — Course Assignment

Rainy Days storefront: a vanilla JavaScript frontend backed by a NestJS REST API.

| Folder | What it is | Docs |
| --- | --- | --- |
| [`frontend/`](frontend) | The assignment itself — vanilla JS storefront, no frameworks | [frontend/README.md](frontend/README.md) |
| [`backend/`](backend) | NestJS API serving the product catalogue and a simulated checkout | [backend/README.md](backend/README.md) |

**Start with [frontend/README.md](frontend/README.md)** — it covers running the project locally,
the JavaScript structure, and the use of AI on this assignment.

Both servers must be running. The backend serves the API on port 8080; the frontend is a static
site served on port 5500.
